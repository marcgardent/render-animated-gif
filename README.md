# Render Animated Image (GIF & WebP)
A Blender extension that allows you to render animated **.webp** (loop=0) and **.gif** images directly within Blender itself.

Available soon in the Blender Extensions Platform!

### Features:
- **Formats**: Modern animated WebP (`loop=0`, 24-bit color + alpha, lightweight) and classic animated GIF.
- **Output Properties Panel**: Dedicated configuration panel in the `Output` tab.
- **Quality Profiles**:
  - **WebP**: Balanced (75%), High Quality (90%), Lossless (100% pixel-perfect), Compact (50%), and Custom (sliders for quality, lossless toggle, presets, compression effort).
  - **GIF**: High (2-Pass palette generation with Bayer dithering), Medium (1-Pass split palette), and Low (fast).
- **Infinite Loop**: Defaults to `loop=0` for seamless continuous playback on web, Discord, stickers, etc.
